# 从零构建 Coding Agent

> 18 章渐进式教程，从 "30 行调用一次 LLM" 到 "750 行完整 Coding Agent"。

## 核心公式

**Coding Agent = LLM + Protocol + Loop + Tools + State**

## 目标读者

- 有 TypeScript / Node.js 基础
- 用过 ChatGPT 但没写过 Agent
- 想理解 Claude Code / Cursor / Cline 背后的原理

## 关于本书

本书通过 18 章渐进式教程，带你从零构建一个完整的 Coding Agent。每章解决一个具体问题，配套可运行的 Demo 代码。最终你将拥有一个 750 行、能读文件、写代码、跑测试的完整 AI 编程助手。

源码仓库：[GitHub](https://github.com/happydog-intj/build-coding-agent-tutorial)
